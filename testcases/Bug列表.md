# iQOO Z10 Turbo 缺陷（Bug）列表

## BUG_PERF_001：省电模式下边充边玩《王者荣耀》导致发热、屏幕触控不跟手

| 字段 | 内容 |
| :--- | :--- |
| **Bug编号** | BUG_PERF_001 |
| **缺陷标题** | 省电模式下边充边玩《王者荣耀》导致发热、屏幕触控不跟手 |
| **所属模块** | 系统/性能 |
| **缺陷类型** | 性能问题（触控/散热） |
| **严重程度** | 中（影响用户体验） |
| **优先级** | 高（核心游戏场景，急需修复） |
| **复现概率** | 必现（100%） |
| **状态** | 待修复 |
| **测试环境** | 硬件：iQOO Z10 Turbo；系统：OriginOS 4；配件：原装120W充电器 |
| **指派给** | 系统性能优化组 |

### 复现步骤
1. 进入设置，开启“省电模式”。
2. 插上原装120W充电器。
3. 打开《王者荣耀》，将画质和帧率设置为最高。
4. 连续游玩15分钟。
5. 在游戏过程中快速滑动屏幕控制角色。

### 预期结果
开启省电模式后，即使边充边玩，温控应保持合理，屏幕触控采样率正常，不出现断触，操作跟手。

### 实际结果
游玩15分钟后机身明显发热，屏幕触控响应变慢，出现不跟手/断触现象，严重影响操作。

### 缺陷分析
省电模式限制了CPU/GPU性能，叠加120W快充与《王者荣耀》高负载，导致温控策略过于激进，触发屏幕触控降采样。建议优化温控与充电调度的优先级策略。

### 附件/证据说明
已通过 Android 开发者选项中的 **“HWUI呈现模式分析”（条形图）** 监控游戏过程中的渲染延迟，并结合系统自带**屏幕录制**功能，记录发热降频期间的触控操作延迟现象。因静态截图无法体现动态卡顿与触控不跟手，故以系统渲染监控数据与主观体验描述作为有效证据。

## BUG_PERF_002：开启省电模式后，多任务切换出现轻微掉帧

| 字段 | 内容 |
| :--- | :--- |
| **Bug编号** | BUG_PERF_002 |
| **缺陷标题** | 开启省电模式后，多任务切换出现轻微掉帧 |
| **所属模块** | 系统动效 |
| **缺陷类型** | 性能问题（界面渲染） |
| **严重程度** | 轻微 |
| **优先级** | 中 |
| **复现概率** | 必现（100%） |
| **状态** | 待修复 |
| **测试环境** | 硬件：iQOO Z10 Turbo；系统：OriginOS 4 |
| **指派给** | 系统UI开发组 |

### 复现步骤
1. 在设置中开启“省电模式”。
2. 依次打开10个常用App，让它们处于后台。
3. 在多个App之间快速来回切换。

### 预期结果
切换动画流畅，无明显掉帧，视觉体验连贯。

### 实际结果
切换过程中出现轻微掉帧，视觉上能感知到卡顿。

### 缺陷分析
省电模式为了降低功耗，限制了GPU渲染能力，导致系统动效无法在16ms内完成渲染，从而产生掉帧。建议在动效渲染上做进一步优化，或提供“均衡/极致省电”档位供用户选择。

### 附件/证据说明
已通过 Android 开发者选项中的 **“HWUI呈现模式分析”（条形图）** 进行抓取。在开启省电模式并进行多任务滑动、切换时，屏幕条形图出现大量明显超过绿线（16ms）的红色、黄色高柱，证明存在UI渲染掉帧。
