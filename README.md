# Android手机整机与系统应用功能测试实战

## 项目简介
对安卓手机（本人设备：iQOO Z10 Turbo）进行整机与系统应用的功能测试、兼容性测试和稳定性测试。

## 测试内容
- **整机功能测试**：通话、短信、WiFi、蓝牙、相机、传感器
- **版本验证与回归测试**：覆盖核心业务流，跟踪Bug生命周期
- **ADB日志抓取**：使用 `adb logcat` 定位App闪退与ANR异常

## 项目结构
- `testcases/`：测试用例与Bug列表
- `测试报告.md`：完整的测试报告
- `README.md`：项目说明文档

## 测试结论
共执行20条用例，通过18条，发现2个有效缺陷。
