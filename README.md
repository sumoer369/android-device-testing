# iQOO Z10 Turbo 整机与系统应用功能测试实战

## 项目简介
基于本人设备 iQOO Z10 Turbo（OriginOS 系统）进行整机与系统应用的功能、性能及稳定性测试。

## 测试内容
- **整机功能测试**：通话、短信、WiFi、蓝牙、相机、传感器
- **系统特性测试**：高刷屏、游戏魔盒（Monster模式）、快充发热
- **ADB日志抓取**：使用 `adb logcat` 定位App闪退与ANR异常
## 项目结构
- `testcases/`：测试用例与Bug列表
- `测试报告.md`：完整的测试报告
- `README.md`：项目说明文档

## 测试结论
共执行20条用例，通过17条，发现3个有效缺陷。
## 缺陷管理：使用禅道（ZenTao）进行 Bug 的提交、指派与生命周期跟踪，输出规范缺陷报告。
