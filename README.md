# iQOO Z10 Turbo 整机与系统应用功能测试实战

## 项目简介
基于真机 iQOO Z10 Turbo（OriginOS 4），针对系统基础应用、高负载游戏及系统省电模式进行功能与性能测试。

## 测试工具
- **日志与性能**：Android HWUI（量化UI渲染掉帧）
- **缺陷管理**：禅道（提交Bug、跟踪生命周期闭环）

## 测试内容
- **功能测试**：系统基础应用操作、多任务后台保活测试。
- **性能测试**：针对“边充边玩《王者荣耀》发热与触控”、“省电模式多任务切换掉帧”进行探索性测试。
- **缺陷记录**：发现并提交2个真实性能缺陷（发热断触、多任务掉帧），使用禅道跟踪修复。

## 项目文件
- `测试设计与缺陷管理记录.md`：Xmind 测试点大纲与禅道 Bug 记录（含真实截图）。
- `测试报告.md`：完整的整机测试报告。
