# iQOO Z10 Turbo 整机与系统应用功能测试实战

> ⚠️ **声明**：本项目为个人自主实战项目，非企业实习项目。旨在完整演练整机测试全流程。

## 项目简介
基于真机 iQOO Z10 Turbo (OriginOS 4, Android 14)，针对系统基础应用、高负载游戏及系统省电模式进行功能与性能测试。

## 测试工具
- **功能与测试设计**：测试用例表格 (等价类、边界值、场景法)、禅道 (提交Bug、跟踪生命周期闭环)
- **性能与日志**：Android HWUI (量化UI渲染掉帧)、开发者选项

## 测试内容
- **功能测试**：系统基础应用操作、多任务后台保活测试。设计20条测试用例，覆盖等价类、边界值、场景法。
- **性能测试**：针对“边充边玩《王者荣耀》发热与触控”、“省电模式多任务切换掉帧”进行探索性测试。
- **缺陷记录**：发现并提交2个可复现性能缺陷（发热断触、多任务掉帧），使用禅道跟踪修复。

## 项目文件
- `testcases/`：手机整机测试用例文件、Bug列表。
- `测试报告.md`：完整的整机测试报告（含质量评估与改进建议）。
- `测试设计与缺陷管理记录.md`：各工具的详细实操记录与真实截图（HWUI掉帧分析、禅道Bug记录等）。
