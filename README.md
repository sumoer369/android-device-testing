# iQOO Z10 Turbo 整机与系统应用功能测试实战

## 项目简介
对 iQOO Z10 Turbo (OriginOS 4) 进行整机与系统应用的功能、稳定性及性能测试。

## 测试工具
- **测试设计**：Xmind（梳理测试点，覆盖功能、异常、性能等维度）
- **缺陷管理**：禅道（提交Bug、跟踪生命周期闭环）
- **日志与性能**：ADB（adb logcat抓取日志）、Android HWUI（量化UI渲染掉帧）

## 测试内容
- **功能测试**：通话、WiFi、蓝牙、相机、快充等模块，设计20+条用例。
- **性能测试**：针对边充边玩《王者荣耀》、省电模式多任务切换等场景进行探索性测试。
- **缺陷记录**：
  - BUG001：省电模式下边充边玩《王者荣耀》导致发热断触。
  - BUG002：开启省电模式后多任务切换出现轻微掉帧。

## 项目文件
- `screenshots/`：包含 HWUI 性能分析、禅道 Bug 列表与详情等截图。
- `testcases/`：测试用例与 Bug 记录文档。
- `测试报告.md`：完整的整机测试报告。
